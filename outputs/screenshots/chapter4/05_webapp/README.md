# ภาพหน้าจอ — Stage 5.2b (เว็บแอป Streamlit แบบหน้าเดียว)

โฟลเดอร์นี้เก็บภาพหน้าจอจริงจากแอป (ต้องถ่ายจากแอปที่รันจริง — ห้ามสร้างภาพปลอม)

## วิธีถ่าย
1. รัน `streamlit run webapp/app.py` จากโฟลเดอร์โปรเจกต์
2. เปิด `http://localhost:8501`
3. เลื่อนดูหน้าเดียว + ดูแถบด้านข้างตาม `docs/chapter4/05_webapp/ui_walkthrough.md`
4. บันทึกภาพลงในโฟลเดอร์นี้ด้วยชื่อไฟล์ตามรายการด้านล่าง

## รายการภาพที่ต้องมี (7 ภาพ)
- [ ] `01_hero.png` — ส่วน hero (พาดหัว "ค้นพบหนังที่ใช่" + ปุ่ม เริ่มต้น)
- [ ] `02_genre_step.png` — ขั้นที่ 1 เลือกประเภท (ปุ่ม pill)
- [ ] `03_rating_step.png` — ขั้นที่ 2 ให้คะแนนภาพยนตร์ (การ์ด + ดาว)
- [ ] `04_results.png` — ขั้นที่ 3 ผลแนะนำ 10 อันดับ (การ์ด 2×5)
- [ ] `05_sidebar_live_preview.png` — แผงควบคุมโมเดล + ตัวอย่างผล Top 5
- [ ] `06_csv_export.png` — ปุ่มบันทึกผลเป็น CSV (+ ตัวอย่างไฟล์ CSV)
- [ ] `07_full_page.png` — ภาพรวมทั้งหน้า
