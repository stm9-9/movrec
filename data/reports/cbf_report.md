# Content-Based Filtering — Implementation & Test Report

## Implementation
- Module: `recommender/content_based/tfidf_model.py` (`ContentBasedModel`).
- Feature text: `genres_text` (Thai genre names) + `overview` (Thai/English).
- Vectorization: `TfidfVectorizer(max_features=5000)`.
- Similarity: cosine via `NearestNeighbors(metric='cosine', k=11)`; source movie excluded.

## Model summary (actual)
- Movies used: **9841**
- Empty-feature rows dropped: **0**
- TF-IDF matrix: **9841 x 5000**
- Pairwise cosine matrix dimension: **9841 x 9841** (lazy, top-k only)

## Limitations
- Thai text is tokenized by whitespace (standard `TfidfVectorizer`); genre names are single space-separated tokens, so the genre signal dominates. A Thai word-segmenter or char n-grams could improve overview matching but was not added to keep dependencies minimal.
- The full dense 9841x9841 cosine matrix is not materialized; item-item similarity is retrieved on demand via a brute-force kNN index (equivalent result, far less memory).
