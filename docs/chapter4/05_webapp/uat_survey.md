# แบบสอบถามการทดสอบการยอมรับของผู้ใช้ (User Acceptance Test)

**ระบบแนะนำภาพยนตร์ (Movie Recommendation System)**

## คำชี้แจง

ระบบแนะนำภาพยนตร์นี้พัฒนาขึ้นโดยใช้เทคนิคเหมืองข้อมูล ผสมผสานการกรองตามเนื้อหา (Content-Based
Filtering) การกรองร่วม (Collaborative Filtering) และแบบผสม (Hybrid) เพื่อแนะนำภาพยนตร์ที่ตรงกับ
ความสนใจของผู้ใช้

โปรดทดลองใช้งานระบบ (เลือกประเภทที่ชอบ → ให้คะแนนภาพยนตร์ → ดูผลแนะนำ) แล้วตอบแบบสอบถาม
ตามความเห็นจริงของท่าน

**เกณฑ์การให้คะแนน:** 1 = น้อยที่สุด, 2 = น้อย, 3 = ปานกลาง, 4 = มาก, 5 = มากที่สุด

## ส่วนที่ 1 — ความคิดเห็นต่อระบบ (Likert 1–5)

| ข้อ | คำถาม | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | ความง่ายในการใช้งานระบบ (เลือกประเภท / ให้คะแนน / ดูผลแนะนำ) | | | | | |
| 2 | ภาพยนตร์ที่แนะนำตรงกับความสนใจของฉัน | | | | | |
| 3 | คำอธิบายเหตุผลการแนะนำ ("เพราะคุณชอบ …") ชัดเจนและเข้าใจง่าย | | | | | |
| 4 | ความสวยงามและการจัดวางหน้าจอ (โทนสี ตัวอักษร การ์ดภาพยนตร์) | | | | | |
| 5 | ความรวดเร็วในการแสดงผลคำแนะนำ | | | | | |
| 6 | ความพึงพอใจโดยรวมต่อระบบแนะนำภาพยนตร์ | | | | | |
