# บทที่ 4 — คู่มือการใช้งานเว็บแอป (UI Walkthrough)

Stage 5.2b — แอป Streamlit แบบหน้าเดียว (ยังไม่ deploy) — หลักฐานประกอบการเขียนบทที่ 4

## วิธีเปิดใช้งาน (รันเองเพื่อจับภาพหน้าจอ)

จากโฟลเดอร์โปรเจกต์ ให้รัน:

```
streamlit run webapp/app.py
```

จากนั้นเปิด `http://localhost:8501` (Streamlit จะแสดง URL ให้)

## โครงสร้างหน้า (single scroll)

หน้าเว็บเป็นหน้าเดียวเลื่อนลงต่อเนื่อง แบ่งเป็น 4 ส่วนหลัก:
1. **Hero** (ส่วนบน) — พาดหัวใหญ่ + ปุ่ม "เริ่มต้น"
2. **ขั้นที่ 1** — เลือกประเภทที่ชอบ (ปุ่ม pill)
3. **ขั้นที่ 2** — ให้คะแนนภาพยนตร์ (ตารางการ์ด 5 คอลัมน์ + ดาว)
4. **ขั้นที่ 3** — ผลแนะนำ (ตารางการ์ด 10 อันดับ)

แถบด้านข้างซ้ายคือ **"แผงควบคุมโมเดล"** — แสดงตลอดเวลา

## ขั้นตอนการใช้งาน + ภาพหน้าจอที่ต้องถ่าย (7 ภาพ)

### 1. Hero (ส่วนบนของหน้า)
- พาดหัวใหญ่ "ค้นพบหนังที่ใช่" (ฟอนต์ Playfair Display) + คำอธิบายสั้น + ปุ่ม "เริ่มต้น"
- **จับภาพ:** ส่วน hero ทั้งส่วน (พาดหัว + ปุ่ม)

### 2. ขั้นที่ 1 — เลือกประเภทที่ชอบ (Genre step)
- เลื่อนลงมาเห็นส่วน "ขั้นที่ 1 — เลือกประเภทที่ชอบ" เป็นปุ่ม pill (บู๊, ผจญ, แอนนิเมชั่น, …)
- กดเลือกได้หลายประเภท
- **จับภาพ:** ส่วนขั้นที่ 1 พร้อมแสดงปุ่มประเภทที่เลือกไว้

### 3. ขั้นที่ 2 — ให้คะแนนภาพยนตร์ (Rating step)
- ส่วน "ขั้นที่ 2 — ให้คะแนนภาพยนตร์" แสดงการ์ดภาพยนตร์ 10 เรื่อง (ตาราง 5 คอลัมน์)
- แต่ละการ์ดมีโปสเตอร์ (2:3) + ชื่อเรื่อง + ดาวให้คะแนน 1–5
- **จับภาพ:** ส่วนขั้นที่ 2 พร้อมตัวอย่างการให้คะแนน

### 4. ขั้นที่ 3 — ผลแนะนำ (Results)
- ส่วน "ขั้นที่ 3 — ผลแนะนำสำหรับคุณ" แสดงการ์ด 10 อันดับ (2 แถว × 5 คอลัมน์)
- แต่ละการ์ดมีโปสเตอร์, ป้ายคะแนน (#อันดับ · คะแนน), ชื่อ, ประเภท, เหตุผล ("เพราะคุณชอบ …")
- ด้านบนมีป้ายบอกวิธีแนะนำและน้ำหนัก α/β
- **จับภาพ:** ส่วนผลแนะนำทั้งส่วน

### 5. แถบด้านข้าง — แผงควบคุมโมเดล (Sidebar with live preview)
- ด้านซ้ายมี "แผงควบคุมโมเดล": ตัวเลือกวิธี (Hybrid A / CF only / CBF only / Popularity)
- เมื่อเลือก Hybrid A → มีแถบเลื่อน α (β = 1−α) พร้อมแสดงค่าน้ำหนัก
- มี **ตัวอย่างผล (Top 5)** อัปเดตตามสถานะปัจจุบันเสมอ
- **จับภาพ:** แถบด้านข้างทั้งแผง (เห็นตัวเลือกวิธี + แถบ α + ตัวอย่าง Top 5)

### 6. บันทึกผลเป็น CSV (CSV export)
- ปุ่ม **"บันทึกผลเป็น CSV"** อยู่ด้านล่างของแถบด้านข้าง
- กดแล้วดาวน์โหลด `recommendations.csv` (คอลัมน์: session, method, alpha, beta, movie_id, title, score, rank)
- **จับภาพ:** ปุ่มดาวน์โหลด + เนื้อหาบางส่วนของไฟล์ CSV

### 7. หน้าเต็ม (Full page)
- เลื่อนดูทั้งหน้า 4 ส่วนพร้อมกัน เพื่อเห็นภาพรวมการจัดวางแบบ HBO Max × Linear
- **จับภาพ:** ภาพรวมทั้งหน้า (จอเดียว)

## หมายเหตุ
- กรณีไม่เลือกประเภทและไม่ให้คะแนน → ผลแนะนำเป็นภาพยนตร์ยอดนิยมพร้อมข้อความแจ้ง
- กรณีเลือกวิธี CF แต่ยังไม่ให้คะแนน → แจ้งเตือนและตกกลับไปภาพยนตร์ยอดนิยม
- ภาพหน้าจอทั้งหมดต้องถ่ายจากแอปที่รันจริง (ห้ามสร้างภาพปลอม)
